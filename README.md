# Totem Skins

Переименуй **Тотем Бессмертия** в наковальне в ник игрока — и он станет «тотемом-из-скина» этого игрока (скин, наложенный на форму тотема). Динамически, для **любого** игрока.

> Rename a **Totem of Undying** in an anvil to a player's name, and it renders as that player's "skin-totem" (their skin mapped onto the totem shape). Works dynamically for **any** player.

![preview](https://github.com/Skr1zzzz/totem-skins)

## ✨ Что умеет / Features
- **Любой ник** — печатаешь ник в наковальне, тотем сразу показывает скин этого игрока (живой предпросмотр).
- **Онлайн-игроки** — скин берётся из списка игроков сервера мгновенно.
- **Оффлайн / любой существующий ник** — скин подгружается с серверов Mojang (асинхронно, с кэшем).
- **Геометрия — как у обычного тотема** (1-в-1): меняется только текстура, размер/форма/положение не трогаются.
- Обычные (непереименованные) тотемы остаются обычными.
- Раскладка skin→totem **пиксель-в-пиксель** совпадает с генератором [minecraftch.ru/skintototem](https://minecraftch.ru/skintototem.html) (снята обратной разработкой).

## ⚙️ Требования / Requirements
- **Minecraft 1.21.11**
- **Fabric Loader** ≥ 0.16
- **Fabric API**
- **Java 21**
- **Клиентский мод** (client-side) — ставится только клиенту, на сервер не нужен. На сервере без мода другие игроки видят обычный тотем.

## 📦 Установка / Install
1. Поставь Fabric Loader для 1.21.11 + Fabric API.
2. Положи `totem-skins-*.jar` в папку `mods/`.
3. В игре переименуй тотем в наковальне в ник игрока.

## 🔧 Как это сделано / How it works
- Mixin в `ItemModelManager.clearAndUpdate` ловит сборку состояния предмета; если это тотем с именем игрока — у уже собранных **ванильных квадов** пересчитываются UV на отдельную текстуру (геометрия не меняется), и подменяется рендер-слой.
- Текстура тотема генерируется из скина в рантайме (`SkinToTotem`) по точной карте пиксель→пиксель, снятой с сайта-генератора калибровочным скином.
- Ник→скин: онлайн — из `PlayerListEntry`; иначе `ApiServices.profileResolver()` + `PlayerSkinProvider` (Mojang), асинхронно, с кэшем успехов и негатив-кэшем несуществующих ников.
- Кэш состояний различается по текстуре (`addModelKey`), чтобы обычный и кастомный тотемы не путались.

## 🏗️ Сборка / Build
```
./gradlew build
```
jar появится в `build/libs/`. JDK 21 (например, java-runtime-delta из PrismLauncher).
